# Project Statement

## Project Title

**My Reminder App**

## Problem Statement

Students often have assignments, study sessions, meetings, and other small tasks that are easy to forget when they are managing several activities at the same time. A simple reminder system can reduce this problem by allowing a user to record a task and receive an alert at a chosen date and time.

The aim of this project is to build a lightweight command-line reminder application using Python.

## Scope

The project focuses on creating and managing personal reminders on a local computer. It includes input validation, date/time processing, background scheduling, reminder alerts, and persistent reminder history.

The project does not currently attempt to provide cloud synchronization, mobile notifications, or multi-user access.

## Target Users

The main target users are students and individual users who want a simple way to schedule and review reminders from a computer terminal.

## High-Level Features

1. Add a reminder.
2. Validate reminder details.
3. Schedule a background alert.
4. Save reminder history locally.
5. View saved reminders.
6. Handle incorrect input safely.
